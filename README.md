# Location Sharing Website

A website that allows you to manually share location updates with friends and spontaneously join their plans.

## Features
- Manual location/plan updates
- Real-time map display of friends' locations
- Friends management
- Activity notifications
- Join friends' plans

## Tech Stack
- Next.js 14+ with React
- Firebase (Auth & Realtime Database)
- Mapbox GL JS
- Tailwind CSS
